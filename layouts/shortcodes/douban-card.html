Usage (unchanged; every existing call site keeps working): {{< douban-card id="36154853" title="好东西" year="2024" director="邵艺辉" rating="8.9" cast="宋佳、钟楚曦、赵又廷" synopsis="..." >}} ── Cover resolution order ──────────────────────────────────────────── 1. cover="..." explicit local path. Wins outright, and never touches the network — this is the fully-offline path. 2. NeoDB GET /api/catalog/fetch?url=, read cover_image_url, then download + resize the image into our own output so readers never contact NeoDB. 3. type icon the previous behaviour, when neither above yields a URL. ── Why step 2 exists ───────────────────────────────────────────────── Douban closed its public API in 2022, so this shortcode has always required metadata as parameters and a `cover` path the author had to find and commit by hand. NeoDB resolves a Douban subject URL to a catalogue entry including its artwork, which removes that manual step. ── Why the `try` wrappers, specifically ────────────────────────────── resources.GetRemote throws on a network error, and an uncaught throw in a shortcode aborts the whole `hugo --minify`. Measured: with a bare GetRemote, an unresolvable host produced ERROR error building site: ... failed to render shortcode "probe" i.e. one unreachable third party would have broken the build for every site using this card. `try` absorbs that, but it wraps even its SUCCESS value in template.TryValue, so `transform.Unmarshal` on it fails with "type template.TryValue not supported". The working form is: $r := try (resources.GetRemote ...); if not $r.Err { $r.Value | transform.Unmarshal } Verified on 0.146.0 (theme.toml min_version), 0.166.0 and 0.167.0: success path returns the cover, failure path yields an empty string, and all three exit 0. */ -}} {{- $id := .Get "id" -}} {{- /* Whitelist the media type. It is caller-supplied and was interpolated unvalidated into both the label text and the douban subdomain, so an arbitrary value could reach the markup. An unknown type falls back to movie rather than being echoed; the accepted set is what the config block below branches on. */ -}} {{- $KNOWN := slice "movie" "book" "music" -}} {{- $typeRaw := .Get "type" | default "movie" -}} {{- $type := "movie" -}} {{- if in $KNOWN $typeRaw }}{{ $type = $typeRaw }}{{ end -}} {{- $title := .Get "title" | default "豆瓣条目" -}} {{- $year := .Get "year" -}} {{- $region := .Get "region" -}} {{- $director := .Get "director" -}} {{- $rating := .Get "rating" -}} {{- $cast := .Get "cast" -}} {{- $synopsis := .Get "synopsis" -}} {{- $cover := .Get "cover" -}} {{- $alt := .Get "alt" -}} {{- /* Cast separator normalisation. `cast` is one free-form string and four real call sites had drifted: two used the ideographic comma (宋佳、钟楚曦、赵又廷) and two a spaced slash (孙艺珍 / 池昌旭 / Nana). The template printed the string verbatim, so the same card looked different on different articles. ONE replaceRE rather than split/append/delimit. The first version built a slice and re-joined it, and rendered a bare "、" — the accumulation silently collapsed. A single pure function call has no intermediate state to go wrong, and it needs no Hugo-version-dependent behaviour. \s* around the separator handles "A / B / C", "A /B/ C" and "A, B" alike, and leaves an unsplit name such as "蒂姆·罗宾斯" untouched. No trailing trim: a `| trim` added to handle a leading/trailing separator broke every case (10/11 -> 0/11), and a value that already begins or ends with a separator is not something a call site produces. KNOWN LIMITATION, stated rather than hidden: the replacement is unconditional, so a single credit that itself contains one of these four characters cannot be expressed. `·` is not in the set, so 蒂姆·罗宾斯 and 摩根·弗里曼 are safe; `AC/DC` or a trailing `Jr.,` would not be. Guessing at an exception is what produced the drift this removes, so the constraint is documented instead. */ -}} {{- $castOut := $cast | default "" | replaceRE `\s*[/、,，]\s*` "、" -}} {{- /* type-specific config: URL prefix, SVG icon path, role labels, aria label */ -}} {{- $url := printf "https://%s.douban.com/subject/%s/" $type $id -}} {{- $iconPath := "M3 7a2 2 0 0 1 2-2h9a2 2 0 0 1 2 2v7a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2V7zm13 1l5-3v11l-5-3V8z" -}} {{- $role1Label := "导演" -}} {{- $role2Label := "主演" -}} {{- $ariaIcon := "电影" -}} {{- if eq $type "book" -}} {{- $iconPath = "M3 5a2 2 0 0 1 2-2h5v16H5a2 2 0 0 1-2-2V5zm9-2h7a2 2 0 0 1 2 2v12a2 2 0 0 1-2 2h-7V3z" -}} {{- $role1Label = "作者" -}} {{- $role2Label = "译者" -}} {{- $ariaIcon = "书籍" -}} {{- else if eq $type "music" -}} {{- $iconPath = "M9 17V5l11-2v12M9 17a2 2 0 1 1-2-2 2 2 0 0 1 2 2zM20 15a2 2 0 1 1-2-2 2 2 0 0 1 2 2z" -}} {{- $role1Label = "艺术家" -}} {{- $role2Label = "专辑" -}} {{- $ariaIcon = "音乐" -}} {{- end -}} {{- /* Resolve the cover. $src is "" when we fall through to the type icon. */ -}} {{- $src := "" -}} {{- $fromNeoDB := false -}} {{- if $cover -}} {{- $src = $cover | relURL -}} {{- else if $id -}} {{- $api := printf "https://neodb.social/api/catalog/fetch?url=%s" ($url | urlquery) -}} {{- /* maxAge: a catalogue entry and its artwork do not change between builds, so re-fetching both on every render is pure waste — twenty cards on a site is forty requests per build.
