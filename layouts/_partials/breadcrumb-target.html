{{- /* breadcrumb-target.html — the URL a post breadcrumb should link to as its parent: the list page for the post's OWN section. Usage: {{ $target := partial "breadcrumb-target.html" . }} 文章 Two rules are encoded here, and both were previously copy-pasted into four templates (single.html, posts/single.html, archives/single.html, ja/single.html) with the same drift risk the shared is-list-section predicate had: 1. Resolve from the page's own .Section, never from mainSections. A site with mainSections = ['posts'] would otherwise point an /archives/ or /ja/ post at /posts/ — a regression that shipped once already. 2. Fall back to a synthesised "/
/" when the section page is absent for the current language. An unresolved target renders href="", which reloads the current page instead of navigating anywhere. The empty-section case is handled by an explicit guard rather than by the behaviour of `site.GetPage "section" ""`. That lookup returns the home page on 0.166.0 — verified — but that is a version-specific result, and this partial feeds every breadcrumb and year-pill href on every supported version. The guard makes the guarantee unconditional rather than inherited from a lookup that was only checked on one of the two. Returns a string, so callers use it directly as the href. */ -}} {{- $page := . -}} {{- $target := "" -}} {{- $sectionPage := site.GetPage "section" $page.Section -}} {{- /* Hugo's `with` has no `else if` — only `if` nests. Resolve the section page first, then branch on the three outcomes. The empty-section case is guarded explicitly rather than relying on `site.GetPage "section" ""` resolving to the home page: that behaviour is only confirmed on 0.166.0, and this partial is the single source of every breadcrumb and year-pill href on every supported version. Without the guard, `printf "/%s/" "" | relURL` would emit "//" — a protocol-relative href that navigates to a host instead of a page. */ -}} {{- if $sectionPage -}} {{- $target = $sectionPage.RelPermalink -}} {{- else if eq $page.Section "" -}} {{- $target = site.Home.RelPermalink -}} {{- else -}} {{- $target = printf "/%s/" $page.Section | relURL -}} {{- end -}} {{- return $target -}}
