{{/* gallery.html — image gallery with sorting and layout options -------------------------------------------------------------------- Usage: {{< gallery "folder-name" → folder, default opts {{< gallery "folder-name" cols="3" → folder + grid cols {{< gallery "folder-name" layout="justified" → folder + masonry {{< gallery "folder-name" sort="name" → sort by filename {{< gallery "folder-name" sort="date" reverse="true" → sort by date desc {{< gallery "folder-name" sort="weight" → sort by 01-foo.jpg prefix {{< gallery images="a.jpg,b.jpg" cols="3" sort="manual" → explicit list, keep order {{< gallery images="a.jpg,b.jpg" captions="Foo|Bar" → per-image captions Captions (v0.1.10+) ------------------------ `captions="A|B|C"` assigns a caption to each image by POSITION, split on the pipe character (so a caption may itself contain commas, which `images=` cannot). Index i of `captions` corresponds to index i of `images`. Extra captions beyond the image count are ignored; images without a caption render none. A caption does two things: 1. Renders as a directly below the image, ALWAYS visible. This aligns the shortcode with render-image.html, which has supported always-on captions since v0.1.9 via markdown title syntax (`![alt](src "caption")`). The previous opacity-on-hover overlay in gallery.css was removed — captions are no longer hidden until hover. 2. Becomes the img `alt` when present. Previously `alt` fell back to the raw path (e.g. "assets/tianjin/tianjin-01.jpg"), which carries no meaning for screen readers or search engines. When `captions` is absent or empty, output is unchanged: no caption means no span and no extra class. Note: `captions` only applies to the `images=` form. The `folder=` form derives its list from .Page.Resources.Match at build time, where per-file captions cannot be attached positionally. Sort options: - name (default): alphabetical by filename - date: by file modification time - weight: by filename prefix number (e.g., "01-foo.jpg" → 1) - manual: insertion order (no sort) Layout options: - grid (default): CSS Grid with `cols` columns. Fixed 4:3 cell aspect. - justified: flexbox masonry where each anchor takes its image's natural aspect ratio. Mix of portrait + landscape → uneven row heights, but every image displays in full (no cropping, no letterbox). flex-basis / flex-grow drive row widths; aspect-ratio per item ensures `width:100% height:100% object-fit:cover` fills exactly. Resolution order for the image list: 1. Folder (1st positional arg, e.g. "gallery/2026-tokyo") — pulled from .Page.Resources.Match, so this works for page-bundle folders 2. images="a.jpg,b.jpg" — comma-separated explicit list, each looked up via .Page.Resources.GetMatch (or fallback to a static-style path) Note on `with`-block around `.Page.Resources.GetMatch`: in Hugo 0.165.x, calling `$.Page.Resources.GetMatch name` directly inside a `range` shortcode context can silently return nil for page-bundle resources. Wrapping the lookup in `with $.Page.Resources { .GetMatch name }` consistently returns the resource. Both call sites reach the same code path logically; this appears to be a template-evaluation order quirk with named-param shortcodes that the `with` block papers over. */}} {{- $folder := "" -}} {{- if .IsNamedParams -}} {{- $folder = .Get "folder" -}} {{- else -}} {{- $folder = .Get 0 -}} {{- end -}} {{- $images := default "" (.Get "images") -}} {{- $cols := default "3" (.Get "cols") -}} {{- $layout := default "grid" (.Get "layout") -}} {{- $sort := default "name" (.Get "sort") -}} {{- $reverse := eq (default "false" (.Get "reverse")) "true" -}} {{- $gap := default "14" (.Get "gap") -}} {{- $captions := slice -}} {{- with (.Get "captions") -}} {{- range (split . "|") -}} {{- $captions = $captions | append (trim . " ") -}} {{- end -}} {{- end -}} {{- $items := slice -}} {{- if $folder -}} {{- range (.Page.Resources.Match (printf "%s/*" $folder)) -}} {{- $items = $items | append (dict "src" .RelPermalink "w" (int .Width) "h" (int .Height) "name" .Name "weight" 999999 "caption" "") -}} {{- end -}} {{- else if $images -}} {{- range $idx, $raw := (split $images ",") -}} {{- $path := trim $raw " " -}} {{- $cap := "" -}} {{- if lt $idx (len $captions) -}} {{- $cap = index $captions $idx -}} {{- end -}} {{- if $path -}} {{- $r := "" -}} {{- with $.Page.Resources -}} {{- $r = .GetMatch $path -}} {{- end -}} {{- if $r -}} {{- $items = $items | append (dict "src" $r.RelPermalink "w" (int $r.Width) "h" (int $r.Height) "name" $r.Name "weight" 999999 "caption" $cap) -}} {{- else -}} {{- $items = $items | append (dict "src" (printf "/%s" $path) "w" 0 "h" 0 "name" $path "weight" 999999 "caption" $cap) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- /* Sort — `weight` extracts the numeric prefix from the filename */ -}} {{- if eq $sort "weight" -}} {{- $weighted := slice -}} {{- range $items -}} {{- $num := 999999 -}} {{- $matches := findRE `^(\d+)-?` .name 1 -}} {{- if $matches -}} {{- $str := index (index $matches 0) 0 -}} {{- $num = int (replace (printf "%v" $str) "-" "") -}} {{- end -}} {{- $weighted = $weighted | append (merge . (dict "_w" $num)) -}} {{- end -}} {{- $weighted = sort $weighted "_w" -}} {{- $items = slice -}} {{- range $weighted -}} {{- $items = $items | append (dict "src" .src "w" .w "h" .h "name" .name "weight" ._w "caption" .caption) -}} {{- end -}} {{- else if ne $sort "manual" -}} {{- $items = sort $items "name" -}} {{- end -}} {{- if $reverse -}} {{- $items = collections.Reverse $items -}} {{- end -}}
