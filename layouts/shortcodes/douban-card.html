Wins outright, and never touches the network — this is the fully-offline path. 2. NeoDB GET /api/catalog/fetch?url=, read cover_image_url, then download + resize the image into our own output so readers never contact NeoDB. 3. type icon the previous behaviour, when neither above yields a URL. ── Why step 2 exists ───────────────────────────────────────────────── Douban closed its public API in 2022, so this shortcode has always required metadata as parameters and a `cover` path the author had to find and commit by hand. NeoDB resolves a Douban subject URL to a catalogue entry including its artwork, which removes that manual step. ── Why the `try` wrappers, specifically ────────────────────────────── resources.GetRemote throws on a network error, and an uncaught throw in a shortcode aborts the whole `hugo --minify`. Measured: with a bare GetRemote, an unresolvable host produced ERROR error building site: ... failed to render shortcode "probe" i.e. one unreachable third party would have broken the build for every site using this card. `try` absorbs that, but it wraps even its SUCCESS value in template.TryValue, so `transform.Unmarshal` on it fails with "type template.TryValue not supported". The working form is: $r := try (resources.GetRemote ...); if not $r.Err { $r.Value | transform.Unmarshal } Verified on 0.146.0 (theme.toml min_version), 0.166.0 and 0.167.0: success path returns the cover, failure path yields an empty string, and all three exit 0. */ -}} {{- $id := .Get "id" -}} {{- $type := .Get "type" | default "movie" -}} {{- $title := .Get "title" | default "豆瓣条目" -}} {{- $year := .Get "year" -}} {{- $region := .Get "region" -}} {{- $director := .Get "director" -}} {{- $rating := .Get "rating" -}} {{- $cast := .Get "cast" -}} {{- $synopsis := .Get "synopsis" -}} {{- $cover := .Get "cover" -}} {{- $alt := .Get "alt" -}} {{- /* Cast separator normalisation. `cast` is one free-form string and four real call sites had drifted: two used the ideographic comma (宋佳、钟楚曦、赵又廷) and two a spaced slash (孙艺珍 / 池昌旭 / Nana).
