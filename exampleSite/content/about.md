This is the example site bundled with [Lumenveil](https://github.com/Hansen1018/hugo-theme-lumenveil).

## Features

- Aurora background with three drifting glow blobs
- Glassmorphism surfaces with `backdrop-filter`
- Automatic light and dark mode (system + manual switch)
- Client-side search powered by Hugo JSON output
- PhotoSwipe-powered image galleries
- Open Graph, Twitter Card, and JSON-LD metadata
